How this works

A quick guide to the turntable control panel, the status light and the e-stop.

Using the control panel

  1. Wait until the banner at the top says Ready and shows a green light. The controls are switched off in every other state.
  2. Choose a direction: clockwise (CW) or counter-clockwise (CCW).
  3. Type an angle in degrees. It must be greater than 0 and no more than 360. Any presets shown just fill in the angle; they never start a move.
  4. Tap Rotate. The light turns blue while the table moves, then green again when it has finished.

Moves are relative: the table turns by the angle you enter from wherever it is now. Only one move runs at a time. Everyone connected to the panel sees the same status, and a command sent while the table is busy is refused.

The panel only works from the same local network as the turntable.

What the light means

The lamp on the panel matches the LED on the machine.

  • Solid red: starting up. Wait for green. This also shows briefly after an e-stop is released, or if LinuxCNC restarts.
  • Solid green: ready. You can send a move.
  • Solid blue: moving. Wait for it to finish.
  • Yellow flashing for 2 seconds: command refused. The panel says why. The light then returns to its normal color.
  • Red and yellow alternating: e-stop engaged. See below.
  • Red flashing: system error. The panel shows the message. See below.
  • Red and blue alternating: shutting down. The turntable is powering off.

A gray light on the panel means the panel has lost contact with the turntable. It reconnects by itself.

E-stop

Press the red e-stop button at any time to cut power to the motor. A move in progress stops immediately, and the light shows red and yellow.

  1. Deal with whatever made you stop the table.
  2. Twist or pull the button to release it.
  3. The turntable restarts itself (solid red) and returns to green in a few seconds.

After an interrupted move the table may sit slightly off from where it thinks it is. This does not matter for relative moves.

If you see an error

A flashing red light and a System error banner mean the turntable can't take commands. The message says what happened and what to do:

  • Press and release the e-stop to try again. This clears the fault and runs the start-up sequence again. If the fault is still there, the error comes back.
  • Restart the turntable. Some problems, such as no network connection, can't be cleared with the e-stop. Use the power button as described below, then start it again.

Power button

Press the power button once to shut the turntable down. The light alternates red and blue, the panel shows Shutting down, and the Pi powers off after a few seconds. Press the button again to start it up.
